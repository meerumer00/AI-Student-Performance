# AI Student Performance Prediction System

## About the Project
This project uses Machine Learning to predict student performance based on attendance, internal marks, assignment scores, and daily study hours.

## Features
- Student input form
- Machine Learning based performance prediction
- Interactive Streamlit web interface
- Instant prediction results

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## Project Files
- `app.py` — Web application
- `main.py` — Main Python program
- `train_model.py` — Model training code
- `student_model.pkl` — Trained Machine Learning model
- `stuedent.csv` — Student dataset (use the actual filename in your repository)
- `requirements.txt` — Required Python libraries

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the dependencies:

   `pip install -r requirements.txt`

5. Run the application:

   `streamlit run app.py`

## Project Goal
To demonstrate how Machine Learning can help estimate student performance from academic and study-related data.
